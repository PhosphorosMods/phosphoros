# Phosphoros: Purple Mysteries

A Minecraft Forge 1.12.2 mod: the Lightfall, a dimension of eternal violet dusk, with Greek myth,
ancient medicine, monsters and the voiced Doctor Ammonius. Formerly released as "Totem of Lucifer";
the mod id is still `lucifertotem`, so existing worlds keep working.

- Loader: Forge 1.12.2 (tested on 14.23.5.2859). Install on client and server.
- Optional: The Aether (aether_legacy) for 1.12.2.
- Build: see the header of `build.sh` (no Gradle; needs MCP-named and SRG Minecraft/Forge jars that are
  not included here). Language check: `python3 tools/check_lang.py build/phosphoros-1.3.3.jar`.
- Contact: phosphoros.mod@gmail.com

**Download:** [Phosphoros 1.3.3 (Beta) on the Releases page](https://github.com/PhosphorosMods/phosphoros/releases/tag/v1.3.3) (`phosphoros-1.3.3.jar`, Forge 1.12.2).
